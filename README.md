# Ballers

A 7v7 football matchmaking mobile app built with React Native + Expo + Firebase.

## Getting Started

### Prerequisites
- Node.js installed
- Expo Go app installed on your phone

### Setup
1. Clone the repo
   git clone <your-github-link>
   cd ballers

2. Install dependencies
   npm install -g expo-cli
   npm install

3. Start the app
   npx expo start

4. Scan the QR code with Expo Go on your phone

## Tech Stack
- React Native + Expo
- Firebase Authentication
- Firestore Database
- expo-router
